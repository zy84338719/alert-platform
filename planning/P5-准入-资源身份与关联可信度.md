# P5 准入 · 资源标识与关联可信度规则（BUF-004）

> P5（Incident 治理）的输入条件：资源身份可信 + 关联结论可分级。本文给出裁决规则，Architecture 评审签字后生效。

## 1. 资源身份可信度（INC-004 输入）

| 层级 | 判据 | 可信度 |
| --- | --- | --- |
| L3 | 平台持有稳定 UID（k8s podUID、DeepFlow `_target_uid`、云资源 ARN） | 直接可用 |
| L2 | 稳定名称+集群+命名空间（Deployment 名等，重启不变） | 可用，标记 name-based |
| L1 | 仅 IP/瞬时名 | **禁止**作为关联键；只允许出现在证据展示 |
| 时间窗 | L2 身份必须在重叠时间窗内才可比（同 IP 先后两个 Pod 属不同对象，T-015） | 强制 |

实现锚点：`fingerprint Identity`（source/cluster/entity_type/uid 维度）+ INC-004 的 UID 历史区间表。

## 2. 关联结论分级（INC-002 输出）

| 级别 | 定义 | 系统动作 |
| --- | --- | --- |
| 自动合并 | 同租户 + L3 身份相同 + 时间窗重叠 + 规则显式 high-confidence | 自动关联（可人工拆分，留审计） |
| 建议 | L2 证据或拓扑/同因启发（同集群+同窗+同变更） | 仅展示建议，不合并 |
| 无证据 | 仅名称/标签相似 | 不产生任何关联结论 |

**红线**：跨租户绝不合并（负例矩阵测试）；关联≠根因（US-01 页面明示）。

- [x] 关联输出结构含 evidence[]（规则+命中的身份层+时间窗）
