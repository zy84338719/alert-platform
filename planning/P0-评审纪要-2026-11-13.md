## 2. ARC-003 验证证据（2026-11-13，全部命令实跑）

环境：go 1.27.3 / buf（go install latest）/ protoc-gen-go（latest）/ protoc libprotoc 36.2（Homebrew）/ hz v0.9.8。

| 命令 | 结果 |
| --- | --- |
| `buf lint` | 通过（`proto/api/api.proto` 按 buf.yaml 豁免） |
| `buf build` | 通过（descriptor 107303 字节） |
| `buf generate` + 临时模块 `go mod tidy && go build ./...` | 通过（7 个 `.pb.go`，依赖 protobuf v1.36.12） |
| `hz new -I proto -idl proto/alert/ingest/v1/ingest.proto`（临时目录） | 通过：`(api.post)` 注解产出 `_v1.POST("/events:batch")` |

本轮修复的三处定稿缺陷（均有联动修改）：

1. `proto/api.proto` → `proto/api/api.proto`：`paths=source_relative` 下原位置与 go_package `gen/go/api` 不一致，生成代码内部 import 不可解析、无法编译。联动：ingest.proto import、buf.yaml ignore 路径。
2. docs/03 `episode_id` → `episode_key`：与 `event.proto` 字段及 DDL `alert_instances.episode_key` 统一（§2 标题同步"三种"→"四种"）。
3. docs/03 指纹公式补 `entity_type`：参考实现 `Identity` 的 EntityType 参与摘要，防止不同类型对象共用 uid 误归并。

四种 ID 一致性核对结论：`transport_id`/`event_key`/`fingerprint`/`episode_key` 在 proto ↔ docs/03 ↔ DDL ↔ 参考实现四方一致。
