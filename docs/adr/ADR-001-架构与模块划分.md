# ADR-001 · 中央控制面 + 区域 Edge + 模块化单仓

状态：已接受（2026-11-14；依据：决策经 P1–P6 八轮实现全部落地并验证——Kafka 异步/至少一次+Outbox/IDL-First/权威状态语义分别在消息链路、回放演练与混沌演练中实证）。选择 Go Monorepo、3 个主要二进制 API/Worker/Edge、Kafka 异步消息和 PostgreSQL 状态。优点：降低同步跨集群 RPC、实现独立扩容和断网缓冲。代价：需要维护 Kafka/PG，并实施幂等、Outbox、Edge 存储运维。替代方案：完全中心化 Webhook（弱网不可用）、完全分布式规则引擎（复杂度过高），均不作为 V1。
