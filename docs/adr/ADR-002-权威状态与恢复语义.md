# ADR-002 · 状态权威与 Source Stale

状态：已接受（2026-11-14；依据：决策经 P1–P6 八轮实现全部落地并验证——Kafka 异步/至少一次+Outbox/IDL-First/权威状态语义分别在消息链路、回放演练与混沌演练中实证）。监控 Firing/Resolved 权威保留在 Prometheus/DeepFlow，平台保有镜像与工单状态。HUATUO Occurrence 无天然恢复。Source 失联必须进入 Stale/Unknown，禁止自动 Resolved。Alertmanager Webhook 不足以完整表达所有上游状态历史，升级时需对账或明确契约切换。
