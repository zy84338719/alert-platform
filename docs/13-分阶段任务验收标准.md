# 13 · 分阶段任务验收标准（Step-level DoD）

本文是 `planning/backlog.csv` 80 个任务的**逐条验收标准**，与 `docs/09` 的测试矩阵、`docs/10` 的阶段闸门配套使用。判定规则：

- 每条标准为**二值判定**（通过/不通过），不接受"基本/大致"；
- "验证方式"列给出证据形态；证据按 docs/09 §4 归档（fixture 来源、压测环境规格、故障注入时间线、RC 变更清单）；
- 验收角色默认：**QA** 验功能/可靠性，**SRE** 验部署/容量，**Architecture** 验契约/设计，Backend 交叉验收；评审类任务由 Architecture 主持；
- 阶段闸门 = 本阶段全任务通过 + 闸门评审签字。**未过闸门不启动下一阶段开发任务**；W13/W14 机动窗口只允许消化欠账与风险收敛，不得塞新功能。
